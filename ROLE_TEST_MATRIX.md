# MIZAN Role Test Matrix

The demo Experience Hub is the launchpad for role-by-role destructive testing.

- Participant: registration/status, arrival slot, queue, result, appeal, certificate.
- JudgeOS: independent judging, event actions, direct/hybrid scoring, undo-as-reversal, lock, next question, audio state.
- Head Judge: review inbox, judge variance, AI observations after lock, appeal decisions, sealing approvals.
- Operations Manager: command center, committee state, queue load, incidents, emergency freeze, simulation.
- Competition Admin: Competition DNA, per-competition registration/judging/questions/results/appeals/certificates/privacy, participants, operations, enterprise tools.
- Scientific Admin: Quran source manifests, question governance, AI capability validation/certification.
- Organization Admin: portfolio, branding, integrations, feature flags and governance boundaries.
- Super Admin: organization provisioning and platform-level controls without hidden result editing.
- Delegation Manager: nominations/travel readiness and participant follow-up.
- Exception Host: human handling of failed/exception arrivals only.
- Auditor: append-only audit review and chain visibility.
- Guardian: consent/minor workflow.
- Support Agent: temporary audited support sessions.
- Broadcast Operator: ceremony/broadcast surface.
- Venue Gate: scan/code check-in and queue-number issuance.
- Waiting Display: privacy-first code calling and next-up board.

For production acceptance, repeat the matrix with real authentication, provider integrations, multi-device offline sync, and load/accessibility/security testing.
