# Accessibility

Target: WCAG 2.2 AA where applicable.

- Semantic labels and visible focus states.
- Keyboard-capable JudgeOS with large touch targets.
- No color-only status communication.
- Reduced-motion support.
- Responsive Arabic RTL and English LTR.
- Kiosk has manual-code fallback.
- No participant is required to install an app; web/kiosk/exception paths coexist.
- Public queue defaults to participant codes rather than names.
