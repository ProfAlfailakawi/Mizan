# مقاطع عبارة إنهاء الموضع

عبارات **غير قرآنية** يقولها المحكم للمتسابق عند نهاية الموضع (مثل «حسبك، جزاك الله خيرًا»).

تُولَّد مرة واحدة ثم تبقى ملفات ثابتة، فلا نداء لأي خدمة أثناء المسابقة ولا حاجة لاتصال:

```bash
MIZAN_GEMINI_API_KEY=<المفتاح> node scripts/generate-cue-audio.mjs
```

تُحفظ باسم `cue-0.wav` … `cue-7.wav` بترتيب العبارات نفسه في
`TRANSITION_PHRASES_AR` (src/lib/judging-integrity.ts)، فيوافق الصوتُ النصَّ المعروض.

ترتيب مصادر الصوت في شاشة المحكم: تسجيل بشري يضبطه المنظّم ← هذه المقاطع ← توليد على
الخادم عند الطلب ← نطق الجهاز. القرآن لا يُولَّد صوتيًا بحال؛ تلاوته من المصدر المعتمد وحده.
