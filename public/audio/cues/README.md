# مقطع عبارة إنهاء الموضع

عبارة إنهاء الموضع ثابتة للجميع: **«حسبك»** وحدها (غير قرآنية)، بلا تناوب ولا بدائل.
الخيار الوحيد للمنظّم: تشغيل التنبيه الصوتي أو إيقافه.

حُذفت المقاطع القديمة `cue-0.wav` … `cue-7.wav` لأنها كانت عبارات بديلة لم تعد تُستعمل.
شاشة المحكم تطلب الآن صوت «حسبك» من الخادم (`/api/public/cue-audio`، يُخزَّن بعد أول توليد)،
ثم نطق الجهاز احتياطًا.

يمكن توليد مقطع ثابت `hasbuk.wav` بالأمر:

```bash
MIZAN_GEMINI_API_KEY=<المفتاح> node scripts/generate-cue-audio.mjs
```

القرآن لا يُولَّد صوتيًا بحال؛ تلاوته من المصدر المعتمد وحده.
