# نشرُ الوثيقتين — وما يلزم قبله

`npm run preflight` يرفع مانعين ما لم تُنشر الوثيقتان:

```
✗ شروط المشاركة غير منشورة
✗ سياسة الخصوصية غير منشورة
```

وهذا الملفّ يشرح كيف يُرفعان.

---

## الخطوات

### ١) املأ ما بين ⟦القوسين⟧

في `TERMS-AR.md` و`PRIVACY-AR.md`. وما بين القوسين **لا يعرفه النظام** ولا يُخمَّن:
الكيان القانونيّ، والاختصاص القضائيّ، وبيانات التواصل، وموقع الاستضافة.

### ٢) تحقّق من المُدَد

المدّتان في §٥ من سياسة الخصوصية هما **الافتراضيّتان** في الشيفرة:

```
audioRetentionDays: 90      documentRetentionDays: 365
```

وكلُّ مسابقةٍ تضبطهما على حدة من «الخصوصية والاحتفاظ». **اقرأ القيمة الفعلية واكتبها
رقمًا صريحًا** — وثيقةٌ تقول ٩٠ ونظامٌ يحفظ ٣٦٥ وثيقةٌ كاذبة.

### ٣) مراجعة محامٍ

**إلزاميّ.** هاتان مسوّدتان تقنيّتان صادقتان عمّا يفعله النظام — وليستا رأيًا قانونيًّا.
وبند «المسؤولية» تُرك فارغًا عمدًا: يكتبه المحامي.

### ٤) انشرهما على رابطٍ ثابت

في أيّ مكانٍ يُفتح بلا تسجيل دخول. ويُفضَّل تحت نطاق الجهة، لكلٍّ رابطُه.

### ٥) اضبط المتغيّرات السبعة

```bash
MIZAN_LEGAL_ENTITY_NAME="الاسم القانونيّ الكامل"

MIZAN_LEGAL_TERMS_URL="https://.../terms"
MIZAN_LEGAL_TERMS_VERSION="1.0"
MIZAN_LEGAL_TERMS_EFFECTIVE="2026-10-01"

MIZAN_LEGAL_PRIVACY_URL="https://.../privacy"
MIZAN_LEGAL_PRIVACY_VERSION="1.0"
MIZAN_LEGAL_PRIVACY_EFFECTIVE="2026-10-01"
```

**النقصُ الجزئيّ ليس نشرًا.** رابطٌ بلا نسخة، أو نسخةٌ بلا تاريخ سريان، يبقى
`LEGAL_DOCUMENT_NOT_PUBLISHED` — فلا يُعرف على أيِّ نصٍّ وقّع الموقِّع ولا متى صار
ساريًا. والسبعةُ كلُّها أو لا شيء.

وفي Cloud Run تُضاف إلى `--update-env-vars` في `cloudbuild.yaml` (ليست أسرارًا).

### ٦) تحقّق

```bash
npm run preflight
```

يجب أن يختفي المانعان.

## قاعدةٌ لا تُكسر: النسخة تُشدّ إلى نصّها

حين تُعدّل نصَّ وثيقةٍ منشورة، **ارفع رقم النسخة وتاريخ السريان**. ولا تُعدّل نصًّا
تحت رقمٍ قائم أبدًا: موافقةُ من سجّل أمسِ مسجّلةٌ بـ«الشروط ١٫٠»، فإن تغيّر نصُّ ١٫٠
صار السجلُّ يشهد على ما لم يره.

---

## ملاحظةٌ يُرجَّح أن يثيرها المحامي

**الموافقةُ اليوم مجموعةٌ في مربّعٍ واحد.**

مربّعُ التسجيل نصُّه:

> «أوافق على شروط المشاركة وسياسة الخصوصية، بما يشمل تسجيل التلاوة والمعالجة التقنية
> المساندة عند تفعيلها.»

وتعليمُه يكتب **أربع** موافقات معًا:

```ts
consents: { terms: ✔, privacy: ✔, audioRecording: ✔, aiProcessing: ✔ }
```

وأكثرُ قوانين حماية البيانات تشترط أن تكون الموافقةُ على المعالجة الاختيارية
(**التسجيل الصوتي** و**المعالجة المساندة**) **مستقلّةً وقابلةً للمنع وحدها** — لا
مشروطةً بالموافقة على الشروط.

والفصلُ عملُ نصف ساعة: أربعةُ مربّعات بدل واحد، والإلزاميّان يمنعان المتابعة
والاختياريّان لا يمنعانها. **ولم يُنفَّذ لأنه قرارُ سياسة لا قرارُ شيفرة:** قد تشترط
لائحةُ المسابقة التسجيل الصوتي، فيصير إلزاميًّا لا اختياريًّا — وذلك قرارُ المالك.

فإن قال المحامي «افصلها» فقل لي، وأفصلها.
