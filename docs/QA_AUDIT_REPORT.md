# سجلّ فحص الجودة الشامل — ميزان

> سجلٌّ حيٌّ يُحدَّث أثناء الفحص. كل بندٍ يذكر: ما وُجد، أين، وما تغيّر، وكيف يُمنع رجوعه.
> القاعدة: لا ميزات جديدة ولا حذف ميزات؛ إصلاح عيوب، وإكمال ما هو قائم، وصقل رسائل الخطأ.

## 1. بيئة الفحص

بيئة الفحص تشغّل **الحزمة الإنتاجية الحقيقية** (`npm run build` + `dist/server.cjs`) مع:

- محاكي Firestore مع تفعيل `firestore.rules` كما هي (لا تجاوز للقواعد).
- **تحقق حقيقي من رموز الدخول**: خادم الهوية المحلي (`scripts/qa/mock-google.mjs`) يوقّع رموز RS256 ويُوجَّه إليه
  طلب شهادات Google عبر محمّل سابق للخادم (`scripts/qa/server-preload.mjs`) — لا يُغيَّر في شيفرة الإنتاج حرف.
- بروتوكول محاكي المصادقة لـ Admin SDK (`setCustomUserClaims`) فتعمل دورة الدعوة ← التفعيل ← المطالبات كما في الإنتاج.
- **لا بيئة عرض (demo)** ولا حسابات عرض: بيانات واقعية مزروعة بسكربت حتمي (`scripts/seed-realistic.ts`).
- متصفح Chromium عبر Playwright بأحجام 390 / 768 / 1280.

التشغيل: `npm run rig:up` ثم `npm run rig:seed` ثم `node scripts/qa/role-tour.mjs <role>` أو `npm run rig:sweep`.
