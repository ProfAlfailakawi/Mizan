# ميزان — ما أُنجز وما بقي

> وثيقةُ تسليم. كلُّ رقمٍ فيها مقروءٌ من الشجرة، لا من ذاكرة. وما لم يُتحقَّق منه مكتوبٌ
> `UNVERIFIED` صراحةً.
>
> آخرُ تحديث: **٢٠ سبتمبر ٢٠٢٦**

---

## ١. الحالة في سطرين

**ميزان نظامُ تشغيلٍ لمسابقةٍ قرآنية يدعم القراءات العشر برواياتها العشرين.**

```
جاهزٌ للإصدار        : 15 / 20
نصُّ الروايات على القرص : 20 / 20   ← لا حرفَ يعتمد على شبكةٍ يومَ المسابقة
صوتُ حفصٍ للعشرين     : 20 / 20
الرجوعُ بين الروايات  : FORBIDDEN
```

**الباقي بندٌ واحدٌ حقيقيّ:** ردُّ اللجنة العلمية على **ثلاث مسائل** في عدّ الآي. لا شيءَ
منه برمجة.

أعِد توليدَ هذه الأرقام بنفسك:
```bash
npm run quran:release-matrix
```

## ٢. القاعدةُ الحاكمة — افهمها قبل أيّ سطرِ كود

> **لا يُعتبر شيءٌ مكتملًا لمجرّد وجود الكود. يجب إثباتُه باختبارٍ أو قياسٍ أو فحصِ
> الإنتاج الفعليّ.**

وينبثق منها ثلاثةُ دروسٍ كلَّفتنا ثمنًا في هذا المشروع:

### أ) «دعوى في نصِّ شيفرةٍ ليست قياسًا»

اختبارٌ يقرأ نصَّ ملفٍّ لا يُثبت أنّ البرنامج يعمل. وُضع اسمٌ عربيٌّ في ترويسة HTTP
فمرّت الاختباراتُ كلُّها — ثمّ ردّ الخادمُ المبنيُّ **500**. (ترويساتُ HTTP بـLatin‑1 فقط؛
العربيُّ فيها يُرمَّز base64.)

> **فإن كان الشيءُ يُشغَّل، شغّله.**

### ب) «حارسٌ لا يعضّ أسوأ من لا حارس»

اختبارٌ يُجرَّب على الرفض وحده قد يرفض كلَّ شيء. فكلُّ حارسٍ هنا **مُجرَّبٌ بطفرة**:
يُعطَب الكودُ عمدًا ويُتأكَّد أنّ الاختبارَ يسقط — وحدَه.

### ج) «قائمةٌ تُنسخ في موضعين تفترق بلا أن ينبّه أحد»

قائمةُ الحزم المطلوبة كانت في **أربعة مواضع**. كلُّ تضييقٍ في موضعٍ أبطله موضعٌ نُسي،
فبقي التغييرُ بلا أثرٍ ثلاثَ مرّات.

> **فإذا رأيتَ قائمةً مكرّرة فاشتقّها، ولا ترقّع موضعًا.**

## ٣. من أين جاء نصُّ القرآن

**سلسلتا إسنادٍ فقط**، وكلتاهما مجمَّدةٌ على القرص ومثبَّتةٌ ببصمة `sha256` تُقابَل في
**كلّ تحميل** — لا مرّةً عند البناء.

| | من أين | مثبَّتٌ عند | الروايات |
|---|---|---|---|
| **إسلام ويب** | `TheAbubakrAbu/Al-Islam-iOS` | `5b3bc321` | ١٢ |
| **المجمّع (مرآة)** | `thetruetruth/quran-data-kfgqpc` | `281dbbe8` | ٨ |

موقعُ المجمّع محجوبٌ عن كثيرٍ من الشبكات، فوصلت حزمُه من مرآةٍ عامّة. ولذلك يفصل السجلُّ
**ثلاثةَ أسئلةٍ لا يجوز خلطُها**:

| الحقل | يجيب عن |
|---|---|
| `publisherAuthority` | **من نشر** — والمجمّعُ ناشرُ حزمِه حقًّا |
| `authority` | **من أين وصلت** — `KFGQPC_MIRROR_DERIVED` لا موقعُ المجمّع |
| `publisherAttribution` | **قوّةُ النسبة** — `MIRROR_REPORTED` لا `OFFICIAL_DIGEST_PROVEN` |

> **الكلُّ اليوم `MIRROR_REPORTED`.** بصماتُ المجمّع الرسميّة (MD5+SHA‑1) مثبَّتةٌ في
> الشجرة وتنتظر ملفّاتِها؛ فمتى وصلت الحزمُ الرسميّة ارتقى الوصفُ تلقائيًّا.

والجردُ الكامل لكلّ مصدرٍ في المشروع: **`docs/SOURCE-INVENTORY.md`**.

## ٤. ما يمنع الروايات الخمس

**نصوصُها تامّةٌ ومُتحقَّقة.** العائقُ **جسرُ المواضع** وحده: حين يختار الحَكَم «البقرة
٢٥٥»، يجب أن يعرف النظامُ أيَّ موضعٍ بعينه في حزمة تلك الرواية يقابل هذا الرقم — فما هو
آيةٌ في عدٍّ قد يكون آيتين في آخر.

والخمس: **البزّي · قنبل · الدوري عن أبي عمرو · السوسي · روح**.

وثلاثُ مسائلَ تحسمها، وكلُّها مقيسةٌ من البايتات لا منقولة:

| المسألة | يخصّ | يفتح |
|---|---|---|
| سورة النبأ: ٤٠ أم ٤١؟ | ابن كثير | البزّي · قنبل |
| سورة الانشقاق: روحٌ ٢٥ ورويسٌ ٢٣ — ولماذا؟ | يعقوب | روح |
| أيُّ عدٍّ تتبعه حزمةُ أبي عمرو؟ (٣ سور) | أبو عمرو | الدوري · السوسي |

**الخطابُ جاهزٌ للإرسال كما هو:** `docs/REQUEST-AYAH-COUNTS.md`.

> **ولا يُدخَل عدُّ آيٍ ولا حدُّ آيةٍ بلا مصدرٍ مُسمًّى.** المقترحُ الآليُّ في
> `artifacts/crosswalk-proposal-*.json` **ظلّيٌّ لا يُفعَّل بذاته** — تراجعه اللجنةُ ثمّ
> تُنقل صفوفُه بمرجعها إلى `src/lib/quran-crosswalk-evidence.ts`.

## ٦. بوّابةُ R2 — لماذا هي حمراء

تفحص البوّابةُ ما يقرؤه المنتجُ من R2. وبعد تجميد النصّ وإلغاء حزم الشرح لم يبقَ إلّا:

```
KFGQPC_REQUIRED_DELIVERY_DATASETS = ['mushaf-pages', 'audio-hafs']
```

والحمرةُ سببُها واحد: **المنشورُ في R2 جردٌ لا كتالوجُ تحقّق.**

| جرد | كتالوج تحقّق |
|---|---|
| يسرد ما صادفه في الدلو | يحمل حالةَ تحقّقٍ لكلّ حزمة وبصمةَ مجلَّد |
| لا مرجعَ تُقاس إليه البايتات | يُكشف به ملفٌّ موجودٌ ببايتاتٍ أخرى |

يُصدره `scripts/kfgqpc-ingest.ts` وحده بعد التحقّق. **ولا تُخضَّر بتليين.**

> وهذه الحمرةُ **لا تمنع النظامَ من العمل**: النصُّ والصوتُ يُخدمان الآن.

## ٧. ما لا يُفعل أبدًا

- **رجوعٌ احتياطيٌّ بين الروايات.** غيابُ حزمة هشام يعني فشلًا صريحًا باسمه، لا نصَّ حفصٍ
  معروضًا على أنه هشام. `cross-reading fallback: FORBIDDEN`.
- **وسمُ مصدرٍ بغير ناشره.** نصُّ إسلام ويب لا يُسمّى KFGQPC، ونصُّ المرآة لا يُسمّى
  الحزمةَ الرسميّة.
- تعطيلُ اختبارٍ أو تليينُ حارسٍ أو تحريكُ عتبةٍ ليخضرّ CI.
- اختراعُ بيانٍ قرآنيٍّ أو قانونيٍّ أو جهةٍ رقابية. **المجهولُ يُكتب `UNVERIFIED`.**
- توليدُ سرٍّ أو كتابتُه — **المستودع عامّ**.
- دمجُ PR نيابةً عن المالك.

## ٨. الأوامرُ التي تحتاجها

```bash
npm run check                  # الفحصُ الكامل: أنواع · اختبارات · بناء · صورة
npm run quran:release-matrix   # حالةُ العشرين بالاسم والسبب
npm run preflight              # موانعُ الإطلاق (يقرأ process.env وحدها)

# حين تصل حزمُ المجمّع الرسميّة:
npm run quran:verify-local  ~/Downloads   # تعيينٌ بالبصمة لا بالاسم
npm run quran:stage-archives ~/Downloads  # إدخالٌ ذرّيّ، لا نصفَ إدخال
```

> `npm run preflight` يقرأ `process.env` وحدها. **موانعُ في صدَفةٍ طازجة، ولا موانع في
> بيئة البوّابة.** لا تُبلّغ بأرقام صدَفتك على أنها الإنتاج.
