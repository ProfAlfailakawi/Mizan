# MIZAN Cost-Aware Deployment

MIZAN must never force an organizer to buy proprietary hardware. The same workflow can run in three deployment profiles.

## Lean
- Arrival: one existing laptop/desktop in full-screen MIZAN Gate.
- QR: built-in camera or manual code entry; USB scanner is optional.
- Queue ticket: digital/screen number. No printer required.
- Waiting board: any TV/display connected to a browser/HDMI source.
- Judges: existing laptop/tablet with browser; physical Judge Pad optional.
- Continuity: one low-cost mini PC edge node when offline continuity is required.
- Human floor: one exception host is the recommended minimum operational human layer; judges remain human by design.

## Balanced
Dedicated kiosk hardware is used only where it removes friction. Existing judge/admin hardware is reused where possible.

## Premium
Dedicated stations, standby edge, optional printers, redundant displays and broadcast equipment for large official events.

The Deployment Studio calculates a suggested hardware map from the current competition size and selected profile. Hardware quantities are planning suggestions, not procurement claims.
