# Deployment Modes

MIZAN is designed for:
- shared cloud SaaS;
- private cloud tenant;
- sovereign/on-premise deployment with on-site edge continuity.

The current package is not deployed. No deployment action is performed by this revision.

Before production: configure authentication/custom claims, database repositories, object storage, secrets, signing keys, monitoring, backups, data residency and organization-specific retention policy. Build containers and infrastructure definitions only after the target environment is chosen.
