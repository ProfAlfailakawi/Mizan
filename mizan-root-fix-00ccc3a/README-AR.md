هذه الحزمة لا ترفع ولا تعدّل GitHub بنفسها. شغّلها داخل نسخة الريبو عند commit `00ccc3a` أو فوق الفرع المبني عليه.

## ما الذي تصلحه؟

1. تمنع خطأ GitHub Actions الثانوي الخاص بـ `docker-build.log`: لا يحاول رفع السجل إلا إذا أُنشئ أصلًا، ولا يحوّل غيابه إلى فشل جديد.
2. تضيف مسارًا خادميًا محميًا لإعادة إصدار رموز رحلة المتسابق عند فقدان الرمز الخام محليًا مع بقاء الـ hash في Firestore.
3. تدوّر QR ذريًا: تنشئ المسارات الجديدة، تحدث hashes في وثيقة المتسابق، وتحذف المسارات القديمة في commit واحد؛ الرمز الخام لا يُخزن في Firestore.
4. تضيف للواجهة إعادة إصدار صريحة بعد تحذير أن QR السابق سيبطل، بدل عرض رسالة طريق مسدود.
5. تضيف اختبار regression يمنع عودة الأسباب نفسها.

## ملاحظة تحقق

التحليل من GitHub أكد أن فشل `docker-build.log` جاء بعد فشل خطوة `npm test`؛ Docker نفسه لم يصل إلى مرحلة التشغيل. هذه الحزمة تعالج ذلك الخطأ الثانوي وتضيف regression جديدًا. يجب تشغيل سكربت التحقق على نسخة الريبو الفعلية للحصول على نتيجة الاختبارات الكاملة لأن بيئة إنشاء هذه الحزمة لم تكن تملك checkout محليًا للريبو.
